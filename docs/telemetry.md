### Blynk
  
The Blynk.io interface requires the codebase provide the following variables:
- Template ID
  - unique identifier for the custom dashboard
  - automatically generated by Blynk upon **dashboard** creation
- Template Name
  - user defined name for the custom template
  - user provides this at time of **template** creation
- Auth Token
  - unique identifier for a transmitting device
  - automatically generated by Blynk upon **Device** creation
  
These three variables are defined in secrets.h which is .gitignored in the codebase to protect authentication tokens.  
Example code from secrets.h.example:
```cpp
#define BLYNK_TEMPLATE_ID   "TMPLxxxxxxxx"
#define BLYNK_TEMPLATE_NAME "Flood Monitor"
#define BLYNK_AUTH_TOKEN    "your-device-auth-token"
```


### WIFI

Accessing WIFI via a local router requires the code provides credentials:   
- Network Name
- Network Password (if applicable)

These three variables are defined in secrets.h which is .gitignored in the codebase to protect network passwords.  

Example code from secrets.h.example:  
```cpp
#define WIFI_SSID     "your-network"
#define WIFI_PASSWORD "your-password"
```

## CLOUD - Blynk.io

Wireless updates of water level and semantic status to an online dashboard is a core deliverable for this project.  
Blynk.io is the provider for this dashboard service.  

Blynk uses virtual pins to transmit data from the ESP32 to the online platform.  

### VPIN Definitions

* V0 = Water Level in cm
* V1 = Status as a string

### Blynk API Examples
The following examples are taken directly from the API Reference section of the blynk.io "New Datastream" setup menu.

#### V0 - Water Level
**GET value**
```cpp
BLYNK_WRITE(V0) {
  double value = param.asDouble();
  Serial.print("V0: ");
  Serial.println(value);
}
```

**UPDATE value**  
```cpp
// Send data on a timer, not inside loop()
BlynkTimer timer;

void sendData() {
  Blynk.virtualWrite(V0, value);
}

void setup() {
  timer.setInterval(1000L, sendData);
}

void loop() {
  Blynk.run();
  timer.run();
}
```

**Set property**
```cpp
// Set on a condition/flag, not in void loop() or other loops
Blynk.setProperty(V0, "{property_name}", "value");
```

#### V1 - STATUS

**GET value**
```cpp
BLYNK_WRITE(V1) {
  String value = param.asStr();
  Serial.print("V1: ");
  Serial.println(value);
}
```

**UPDATE value**  
```cpp
// Send data on a timer, not inside loop()

void sendData() {

void setup() {

}

void loop() {

}
```

**Set property**
```cpp

```
